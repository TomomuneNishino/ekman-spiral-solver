   最も細かい 2 つの格子から 2 次の Richardson 外挿を行うと -45.00000000 度になる。

   が設計どおり 2 次精度で効いていることを意味する。

   [合格] 2. 海面の偏角（Richardson 外挿値）

-- 3. 鉛直積分したエクマン輸送（層全体で運ばれる水の量） ---------------------------
                            東西成分 M_x [kg/(m·s)]  南北成分 M_y [kg/(m·s)]
   -------------------------------------------------------------------------
                    数値解             2.900887e-13             -9.696888e+2
     解析解 (τ_y − iτ_x)/f              0.000000e+0             -9.696888e+2

   輸送の向きは東から -90.0000 度、つまり東向きの風のちょうど 90° 右である。海底
   を応力なしにすると、境界を横切る応力は上端の風応力と下端のゼロだけになる。その
   ため、この等式は格子の粗さにも領域の深さにもよらず、離散のレベルで厳密に成り立
   つ。

   [合格] 4. 輸送が (τ_y − iτ_x)/f と一致する
          結果 1.784e-15   期待 < 1e-12（厳密に成立）
   [合格] 5. 輸送が格子数 N と深さ H によらない
          結果 4.235e-14   期待 24 通りすべてで < 1e-11

   --------------------------------------------------------------------
           1        7.731e-1             7.358e-1              2.486e-5
           2        2.739e-1             2.707e-1              6.457e-5
           3        9.931e-2             9.957e-2              3.413e-5

   海底に粘着条件を課すと底面摩擦が運動量を抜き取るため、輸送は古典値より sech(λH)

          結果 3.413e-5   期待 < 1e-4（空間離散化誤差 O(Δz²)）

      コリオリ力の仕事 / 風の入力           3.345e-17

-- 6. 慣性振動の厳密解に対する時間収束（時間刻みを細かくすると厳密解に近づくか） ---
     ステップ数   Δt [s]  輸送 M の相対誤差   次数
   -----------------------------------------------
             50  3046.37           6.361e-2     --
            100  1523.18           1.609e-2  1.983
            200   761.59           4.034e-3  1.996
            400   380.80           1.009e-3  1.999
            800   190.40           2.523e-4  2.000
           1600    95.20           6.308e-5  2.000

   運動方程式を層全体で鉛直積分すると粘性項が完全に消え、dM/dt = T − ifM だけが残
   る。その解 −i(T/f)(1 − exp(−ift)) には ν も H も格子も含まれないので、時間積分
   の誤差だけを切り出して測ることができる。

   実際、格子数 N = 16, 64, 256 のいずれでも誤差は 4.0335e-3、4.0335e-3、4.0335e-
   3 と一致する。

   [合格] 12. 時間精度の次数（時間刻みを半分にすると誤差が 1/4 になるか）
          結果 1.9999   期待 2.00 ± 0.05
   [合格] 13. 誤差が鉛直格子の細かさによらない
          結果 1.177e-12   期待 < 1e-9

-- 7. 定常状態でのエネルギー収支（風が入れる仕事と粘性が奪う仕事の釣り合い） -------
     格子数 N  風の入力 P [W/m²]  粘性散逸 ε [W/m²]  |P − ε| / P  P と解析値の差
   -----------------------------------------------------------------------------
           64        5.579479e-3        5.579479e-3    4.664e-16        8.827e-3
          128        6.171322e-3        6.171322e-3    5.622e-16        2.200e-3
          256        6.478545e-3        6.478545e-3    4.016e-16        5.495e-4
          512        6.634962e-3        6.634962e-3    4.968e-15        1.373e-4
         1024        6.713871e-3        6.713871e-3    1.163e-14        3.433e-5

   ここでの「定常」は、同じ風が吹き続けて流れが時間変化しなくなった状態（∂W/∂t = 
   0）を指す。定常での解析的な入力は |τ|²/(ρ₀ f D_E) = 6.793246e-3 W/m² である。
   この式に隠れている cos(45°) は、上で測った海面の偏角そのものなので、2 つの結果
   は同じ事実を別の角度から見ているにすぎない。

   海面直下の半セル分を両辺に加えると、N = 1024 で P = 6.793479e-3、ε = 6.793479e
   -3 W/m² となり完全に一致する。

   「P が |τ|²/(ρ₀ f D_E) に収束する」の次数も同じ読み方で、格子数 N を倍にすると
   風の仕事率が解析値へ 1/4 ずつ近づくことを表す。

   [合格] 14. 定常状態で風の入力と粘性散逸が等しい（離散）
          結果 1.163e-14   期待 < 1e-12
   [合格] 15. 海面の半セル分を補正した入力と散逸が一致する
          結果 1.149e-14   期待 < 1e-12
   [合格] 16. P が |τ|²/(ρ₀ f D_E) に収束する
          結果 2.0001   期待 2.00 ± 0.10

-- 8. 回転がエネルギーを作ってはいけない（陰解法と陽解法の比較） -------------------
             スキーム  エネルギーの相対変化  理論予測
   --------------------------------------------------
     Crank–Nicolson法             9.770e-15  厳密に 0
          前進Euler法              6.171e+0  6.171e+0

   粘性も風もない状況では、コリオリ力は速度ベクトルの向きを変えるだけなので、エネ
   ルギーは一定でなければならない。Crank–Nicolson法が施す Cayley 変換は絶対値が厳
   密に 1 である。一方で前進Euler法は (1 − ifΔt) を掛けるが、その絶対値は 1 を超
   えるため、エネルギーを勝手に作り出す。しかもその増え方は理論予測と 14 桁一致す
   る。このシミュレーターを陰解法にした理由がこれである。

   [合格] 17. Crank–Nicolson法はコリオリ回転だけを解いたときエネルギーを保存する
          結果 9.770e-15   期待 < 1e-12
   [合格] 18. Euler法による |W| の増加が |1 − ifΔt|^(2n) − 1 と一致する
          結果 1.540e-14   期待 < 1e-3

-- 9. 緯度依存の風が駆動するエクマン湧昇（層の底に生じる鉛直流） -------------------
     南北格子数 Ny  w_e の相対誤差   次数
   --------------------------------------
                32        6.413e-3     --
                64        1.606e-3  1.998
               128        4.015e-4  1.999
               256        1.004e-4  2.000

   鉛直流速の最大値は 46.9 m/年で、実際に観測されるエクマン湧昇と同じオーダーであ
   る。南北に周期境界を課しているので湧昇と沈降は厳密に相殺しなければならず、正味
   の流量は -3.331e-16 m²/s になっている。

   「w_e が curl(τ/f)/ρ₀ に収束する」の次数は、南北の格子数 Ny を倍にすると湧昇速
   度の誤差が 1/4 になることを表す。ここで測っているのは鉛直方向ではなく、輸送の
   南北微分に使っている中心差分の精度である。

   [合格] 19. w_e が curl(τ/f)/ρ₀ に収束する
          結果 1.9999   期待 2.00 ± 0.05
   [合格] 20. 湧昇と沈降が相殺する
          結果 5.604e-17   期待 < 1e-14
